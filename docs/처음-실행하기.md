# 처음 실행하기 (윈도우 기준)

프로그래밍이나 깃허브를 처음 써도 따라 할 수 있게 쓴 문서입니다.
순서대로만 하면 됩니다. **1번부터 4번까지 하면 영상이 나옵니다.**

> 맥이라면 맨 아래 [맥 사용자](#맥-사용자) 항목을 보세요.

---

## 1. 준비물 설치 (처음 한 번만)

### 1-1. 파이썬

1. https://www.python.org/downloads/ 에서 **Download Python** 버튼 클릭
2. 다운로드한 파일 실행
3. ⚠️ **설치 첫 화면 맨 아래 `Add python.exe to PATH` 를 반드시 체크**하고 Install
   - 이거 안 하면 나중에 "python은(는) 내부 또는 외부 명령이 아닙니다" 오류가 납니다

### 1-2. ffmpeg (영상 처리 엔진)

윈도우 검색창에 **`powershell`** 을 치고 실행한 뒤, 아래를 붙여넣고 엔터:

```powershell
winget install Gyan.FFmpeg
```

설치가 끝나면 **powershell 창을 닫고 새로 열어야** 인식됩니다.

> `winget` 이 없다는 오류가 나면: https://www.gyan.dev/ffmpeg/builds/ 에서
> `ffmpeg-release-essentials.zip` 을 받아 `C:\ffmpeg` 에 풀고,
> `C:\ffmpeg\bin` 을 시스템 환경변수 Path 에 추가하세요.

### 1-3. 한글 폰트 (자막용)

윈도우에는 이미 **맑은 고딕**이 있어서 그냥 써도 됩니다.
더 예쁜 자막을 원하면 [Noto Sans KR](https://fonts.google.com/noto/specimen/Noto+Sans+KR)
을 받아 설치하세요 (무료).

---

## 2. 코드 받기

⚠️ **중요**: 코드는 저장소 첫 화면(`main`)이 아니라 **`claude/game-youtube-video-editor-j1tfxm`
브랜치**에 있습니다. 그냥 다운로드하면 빈 파일만 받아집니다.

1. 깃허브 저장소 페이지를 엽니다
2. 파일 목록 위 왼쪽에 있는 **브랜치 선택 버튼**(보통 `main` 이라고 적힌 버튼)을 누릅니다
3. 목록에서 **`claude/game-youtube-video-editor-j1tfxm`** 을 고릅니다
4. 오른쪽 초록색 **`< > Code`** 버튼 → **Download ZIP**
5. 받은 zip 을 압축 풀기. 예를 들어 `C:\gameedit` 에 풉니다
   - 압축을 풀면 폴더 안에 `README.md`, `gameedit`, `assets` 같은 게 보여야 정상입니다

---

## 3. 설치

압축 푼 폴더(`README.md` 가 보이는 그 폴더)를 **파일 탐색기로 연 다음**,
주소창에 `cmd` 라고 치고 엔터를 누르세요. 그 폴더에서 검은 창이 열립니다.

거기에 아래를 한 줄씩 입력합니다.

```cmd
pip install -e .
```

그 다음 제대로 설치됐는지 확인:

```cmd
gameedit doctor
```

이렇게 나오면 성공입니다.

```
ffmpeg  : C:\...\ffmpeg.exe
음성인식 : none  → `pip install faster-whisper` ...
기본 밈팩 : 28개 밈
```

`ffmpeg : ✗ 없음` 이 뜨면 1-2 단계를 다시 하세요. (창을 새로 열었는지 확인)

### 자막을 자동으로 만들고 싶다면 (선택)

말한 내용을 알아서 자막으로 만들어 줍니다. 용량이 좀 큽니다(수백 MB).

```cmd
pip install faster-whisper
```

안 깔아도 됩니다. 그 경우 자막 없이 컷 편집 + 밈만 들어갑니다.

## 4. 실행

```cmd
gameedit auto "C:\영상\오늘방송.mp4" -t 10m
```

- 큰따옴표 안에 **영상 파일의 전체 경로**를 넣으세요
  (파일을 검은 창에 드래그해서 놓으면 경로가 자동으로 입력됩니다)
- `-t 10m` 은 "최종 10분짜리로 만들어 줘" 라는 뜻입니다. `-t 8m`, `-t 15m` 등

기다리면 이런 순서로 진행됩니다.

```
[1/4] 영상 정보 확인
[2/4] 오디오 추출 및 흥분도 분석
[3/4] 장면 전환 검출
[4/4] 음성 인식(자막)
[편집 계획 수립]
[렌더링]
완성: out\final.mp4  (10:24)
```

**결과물**

| 파일 | 내용 |
| --- | --- |
| `out\final.mp4` | 완성된 편집본 |
| `work\오늘방송\plan.html` | 어디를 왜 잘랐는지 보여주는 검수 화면 (더블클릭하면 브라우저로 열림) |
| `work\오늘방송\subtitles.srt` | 유튜브에 따로 올릴 수 있는 자막 파일 |

> 처음엔 짧은 영상(5~10분)으로 한 번 돌려 보세요. 3시간짜리는 분석에만 오래 걸립니다.

---

## 5. 마음에 안 드는 부분 고치기

`work\<영상이름>\plan.html` 을 열어서 확인한 뒤, 같은 폴더의 **`plan.json`** 을
메모장으로 열어 고치면 됩니다.

- 필요 없는 하이라이트 → `clips` 목록에서 그 덩어리 삭제
- 자막 오타 → `subtitles` 안의 글자 수정
- 밈 위치 → `memes` 안의 `start` 숫자(초) 조정

고친 다음 다시 렌더링만 하면 됩니다. (분석을 다시 하지 않아 훨씬 빠릅니다)

```cmd
gameedit render
```

편집 방향 자체를 바꾸고 싶으면(더 길게/짧게, 밈 줄이기 등):

```cmd
gameedit plan -t 15m --set memes.max_per_minute=2
gameedit render
```

## 자주 나는 오류

**`'gameedit'은(는) 내부 또는 외부 명령... 이 아닙니다`**
설치는 됐는데 명령어 경로를 못 찾는 경우입니다. 앞에 `python -m` 을 붙이세요.

```cmd
python -m gameedit auto "C:\영상\오늘방송.mp4" -t 10m
```

**`'python'은(는) 내부 또는 외부 명령... 이 아닙니다`**
1-1 에서 `Add python.exe to PATH` 체크를 안 한 겁니다. 파이썬을 다시 설치하면서
그 체크박스를 켜세요. (또는 `python` 대신 `py` 로 시도)

**자막이 □□□ 로 나옴**
한글 폰트를 못 찾은 경우입니다. 이렇게 지정하세요.

```cmd
gameedit render --set subtitles.font="맑은 고딕"
```

**`ffmpeg 를 찾을 수 없습니다`**
ffmpeg 설치 후 검은 창을 **새로 열지 않아서** 생깁니다. 창을 닫고 다시 여세요.

**하이라이트가 엉뚱한 데를 잡음**
게임마다 다릅니다. 조용한 게임이면 목소리 비중을 낮추고 대사 위주로:

```cmd
gameedit plan --set highlight.weights.audio=0.6 --set highlight.weights.keyword=2.0
gameedit render
```

**중간에 멈췄어요 / 오래 걸려요**
분석 결과는 저장돼서 다시 안 합니다. 같은 명령을 다시 실행하되
`--reuse-analysis` 를 붙이면 분석을 건너뜁니다.

```cmd
gameedit auto "C:\영상\오늘방송.mp4" -t 10m --reuse-analysis
```

## 맥 사용자

```bash
# 준비물
brew install python ffmpeg

# 코드 받기 (터미널에서)
git clone -b claude/game-youtube-video-editor-j1tfxm <저장소 주소>
cd youtube-editing-

# 설치 및 실행
pip3 install -e .
gameedit doctor
gameedit auto ~/Movies/오늘방송.mp4 -t 10m
```

한글 폰트는 맥에 기본 탑재된 `Apple SD Gothic Neo` 를 쓰면 됩니다.

```bash
gameedit render --set subtitles.font="Apple SD Gothic Neo"
```
