# 폰으로 편집하기

**폰으로 조작하고, 무거운 편집은 컴퓨터가 합니다.**
앱을 설치할 필요가 없고 아이폰·안드로이드 모두 됩니다.

```
   📱 폰                          💻 컴퓨터
 영상 올리기  ──── 와이파이 ────▶  분석·컷편집·밈·자막·인코딩
 진행률 보기  ◀───────────────    (전원만 켜 두면 됨)
 결과 미리보기·저장 ◀──────────
```

> **왜 폰에서 직접 안 하나요?**
> 3시간짜리 영상을 폰에서 인코딩하면 배터리가 먼저 죽습니다.
> 폰은 화면만 담당하고 계산은 컴퓨터가 하는 게 훨씬 빠르고 안정적입니다.

---

## 1. 컴퓨터에서 서버 켜기 (한 번만)

폴더 안의 **`모바일로실행.bat`** 을 더블클릭하세요. (맥은 `모바일로실행.command`)

처음 실행하면 윈도우 방화벽 창이 뜹니다. **"액세스 허용"** 을 눌러야 폰에서 접속됩니다.

검은 창에 이런 게 나옵니다.

```
==================================================
  📱 폰에서 아래 주소로 접속하세요

      http://192.168.0.15:8000/?k=4821

  · 폰과 이 컴퓨터가 같은 와이파이에 있어야 합니다
  · 편집이 끝날 때까지 이 창을 켜 두세요
==================================================
```

## 2. 폰에서 접속

폰 브라우저(사파리·크롬)에 위 주소를 **그대로** 칩니다. 끝의 `?k=4821` 까지 포함해야 합니다.
숫자는 실행할 때마다 바뀌는 접속 번호로, 같은 와이파이의 다른 사람이 함부로 못 쓰게 막아 줍니다.

> **홈 화면에 추가**해 두면 앱처럼 쓸 수 있습니다.
> 사파리: 공유 → 홈 화면에 추가 / 크롬: ⋮ → 홈 화면에 추가

## 3. 편집하기

1. **📤 폰에서 영상 올리기** — 갤러리에서 영상을 고르면 컴퓨터로 전송됩니다
   - 컴퓨터에 이미 영상이 있으면 **"컴퓨터에 있는 영상"** 목록에서 고르세요. 전송이 필요 없어 훨씬 빠릅니다
2. **완성본 길이** 선택 (3·5·10·15·20분)
3. 밈 / 자막 / 쇼츠(세로) 스위치 설정
4. **✨ 편집 시작**

시작하면 **폰을 꺼도 됩니다.** 컴퓨터가 알아서 만듭니다. 나중에 다시 접속해서
작업 목록을 보면 완료돼 있습니다.

## 4. 결과 확인

- 진행률과 현재 단계가 실시간으로 보입니다
- 끝나면 폰에서 **바로 재생**해서 확인할 수 있습니다
- **⬇️ 폰에 저장하기** 를 누르면 갤러리에 받아집니다 (그대로 유튜브에 올리면 됩니다)

## 5. 마음에 안 들면

**✂️ 클립·자막 고치기** 를 누르면

- 하이라이트가 썸네일과 함께 나옵니다. **빼고 싶은 장면은 체크 해제**
- 자막은 눌러서 바로 고칠 수 있습니다 (오타·게임 용어 수정)
- **🔄 이대로 다시 만들기** 를 누르면 다시 인코딩합니다

이때는 분석을 다시 하지 않아서 처음보다 훨씬 빠릅니다.
클립을 빼면 뒤에 있던 밈·자막 위치도 알아서 당겨집니다.

---

## 자주 겪는 문제

**폰에서 주소를 쳤는데 안 열려요**
- 폰이 **같은 와이파이**에 있는지 확인하세요 (5G/LTE 로는 안 됩니다)
- 윈도우 방화벽 창에서 "액세스 허용" 을 눌렀는지 확인하세요
- 컴퓨터의 검은 창이 켜져 있어야 합니다

**"🔒 접속 번호가 필요합니다" 가 떠요**
주소 끝의 `?k=숫자` 를 빼먹었습니다. 컴퓨터 화면의 주소를 전부 입력하세요.
서버를 다시 켜면 번호가 바뀝니다. 매번 같은 번호를 쓰려면:

```
gameedit serve --key 1234
```

**업로드가 너무 느려요**
와이파이로 GB 단위 파일을 보내는 건 원래 느립니다. 컴퓨터로 녹화한 영상이라면
업로드하지 말고 **"컴퓨터에 있는 영상"** 목록에서 고르세요.
그 목록에 보이게 하려면 영상을 `내 문서\Videos` (맥은 `~/Movies`) 에 두거나,
서버를 켤 때 폴더를 지정하세요.

```
gameedit serve --watch "D:\녹화"
```

**밖에서도 쓰고 싶어요**
집 밖에서 쓰려면 공유기 포트포워딩이나 [Tailscale](https://tailscale.com) 같은
가상 사설망이 필요합니다. 다만 인터넷에 그대로 열어 두는 건 권하지 않습니다.

**컴퓨터를 끄면요?**
편집 중이던 작업은 멈춥니다. 이미 완성된 영상은 그대로 남아 있고,
서버를 다시 켜면 작업 목록에 다시 나타납니다.

---

## 명령어로 세밀하게

```bash
gameedit serve                      # 기본 (포트 8000, 접속 번호 자동)
gameedit serve --port 9000          # 포트 바꾸기
gameedit serve --key 1234           # 접속 번호 고정
gameedit serve --no-key             # 접속 번호 없이 (집 네트워크에서만)
gameedit serve --watch "D:\녹화"     # 폰에서 고를 수 있는 폴더 추가
```

편집된 결과물은 컴퓨터의 `work/mobile/jobs/<작업번호>/final.mp4` 에도 그대로 있습니다.
