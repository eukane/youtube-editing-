# 폰만으로 쓰기 (안드로이드)

컴퓨터 없이 **갤럭시 안에서 편집기를 통째로 돌리는** 방법입니다.
Termux 라는 앱으로 폰 안에 리눅스 환경을 만들어 파이썬과 ffmpeg 를 설치합니다.

> 아이폰은 이 방법이 안 됩니다. iOS 는 앱 밖에서 프로그램을 돌릴 수 없습니다.

---

## 1. Termux 설치 (5분)

⚠️ **플레이스토어 말고 F-Droid 에서 받아야 합니다.** 플레이스토어 버전은
업데이트가 끊겨서 설치가 중간에 실패합니다.

1. 크롬으로 **https://f-droid.org/packages/com.termux/** 접속
2. **Download APK** → 설치 (출처를 알 수 없는 앱 허용 필요)
3. Termux 를 엽니다. 검은 화면에 `$` 만 보이면 정상입니다

## 2. 편집기 설치 (10~20분)

Termux 에 아래 한 줄을 붙여넣고 엔터 (길게 눌러서 붙여넣기)

```bash
pkg install -y git && git clone --depth 1 https://github.com/eukane/youtube-editing-.git ~/gameedit && bash ~/gameedit/install.sh
```

중간에

- **저장소 권한 요청**이 뜨면 → **허용** (폰 안의 영상을 읽어야 합니다)
- 설치 중 뭔가 물어보면 → 그냥 엔터

끝나면 이렇게 나옵니다.

```
✅ 설치 끝!
이제 Termux 에서 아래 명령만 치면 됩니다.
    edit
```

## 3. 쓰기

Termux 에서:

```bash
edit
```

주소가 나옵니다.

```
📱 준비됐습니다. 크롬을 열고 아래 주소로 들어가세요
      http://localhost:8000/
```

**크롬을 열고 `localhost:8000` 을 입력**하면 편집 화면이 뜹니다.
(Termux 는 끄지 말고 그대로 두세요. 홈 버튼으로 나가는 건 괜찮습니다.)

화면에서

1. **폰에 있는 영상** 목록에서 편집할 영상 선택
   (갤러리·다운로드 폴더가 자동으로 보입니다)
2. 완성본 길이 선택
3. **✨ 편집 시작**
4. 끝나면 미리보기 → **⬇️ 폰에 저장하기**

크롬에서 그 주소를 **홈 화면에 추가**해 두면 앱처럼 쓸 수 있습니다.

## 대사 자막을 넣으려면

### 방법 1 — .srt 파일 (권장)

유튜브에 영상을 올리면 자동 자막이 만들어집니다. 그걸 `.srt` 로 받아
영상과 **같은 폴더에 같은 이름으로** 두면 편집기가 알아서 씁니다.

    내영상.mp4
    내영상.srt   ← 이렇게

폰에서 음성 인식을 돌리는 것보다 **빠르고 정확합니다.**

### 방법 2 — 폰에서 직접 음성 인식 (선택)

안드로이드에서는 PC 용 음성 인식(faster-whisper)이 돌아가지 않습니다.
대신 C++ 로 만든 **whisper.cpp** 를 설치합니다.

```bash
bash ~/gameedit/install-subtitles.sh
```

빌드에 5~15분, 모델 내려받기에 몇 분 걸립니다. 한 번만 하면 됩니다.

설치해도 **기본은 꺼져 있습니다.** 편집 설정에서 **"폰에서 음성 인식하기"**
를 켜야 씁니다. 켜기 전에 아래를 알고 계세요.

- **느립니다** — 1시간 영상에 1시간 40분~2시간 30분 (G99 실측)
- **한국어 정확도가 낮습니다** — 게임 용어·줄임말을 자주 틀립니다

그래서 **1~2분짜리 쇼츠**에만 권합니다. 긴 영상은 방법 1 을 쓰세요.

더 큰 모델을 받아 정확도를 조금 올릴 수 있습니다 (대신 더 느리고 메모리를
더 씁니다). 받아 두면 편집기가 메모리를 보고 알아서 큰 쪽을 고릅니다.

```bash
bash ~/gameedit/install-subtitles.sh small
```

## 얼마나 걸리나요

**추정하지 말고 직접 재 보세요.** 기기마다 열 배 넘게 차이가 나서
표에 적힌 숫자는 내 폰에 안 맞습니다.

편집 설정 화면 맨 아래 **"자막 만드는 시간 재보기 → 재보기"** 를 누르면,
영상 가운데에서 짧은 조각 두 개를 실제로 돌려 보고 알려 줍니다. 30초쯤 걸립니다.

    이 영상: 약 12분
    1시간짜리면 약 34분
    오디오 1분당 34초 · ggml-base.bin

    인식된 대사 — 맞는지 직접 보세요
    아 이거 왜 죽어 진짜 로토무한테 지는 게 말이 되냐

같이 나오는 **인식된 대사**를 꼭 읽어 보세요. 알아볼 수 없는 글이면 모델이
너무 작은 것이니 `bash ~/gameedit/install-subtitles.sh small` 로 큰 모델을 받으면 됩니다.
**메모리 경고가 뜨면 그 모델은 쓰지 마세요.** 느린 게 아니라 기기가 멈춥니다.

Termux 에서 명령으로 재도 됩니다.

    python -m gameedit speedtest ~/storage/shared/DCIM/영상.mp4

참고용 대략치 (실제로는 재 보세요):

| 단계 | 1시간짜리 원본 기준 |
| --- | --- |
| 소리 분석 | 2~5분 |
| 폰 음성 인식 (base) | **1시간 40분~2시간 30분** ← 기본은 꺼져 있습니다 |
| 컷 편집 + 밈·자막 합성 | 10분 결과물 기준 10~25분 |

자막은 **밖에서 만든 .srt 를 넣는 쪽**이 빠르고 정확합니다 (위 방법 1).
폰 음성 인식은 기본으로 꺼져 있고, 켜면 화면이 예상 시간을 미리 알려 줍니다.

처음에는 **10분 이하 짧은 영상**으로 한 번 돌려보고 감을 잡는 걸 권합니다.

## 이런 영상도 됩니다

- **세로 영상** — 폰으로 찍은 세로 영상은 회전 정보를 읽어 그대로 세로로 뽑습니다
- **말이 없는 영상** — 마이크 없이 녹화했거나 조용한 영상은 소리로 고를 수가 없어서
  균등 간격으로 잘라 줍니다. 그렇게 했다는 안내가 화면에 뜹니다
- **짧은 영상** — 10초짜리로 시험해 봐도 결과가 나옵니다

## 폰에서 돌릴 때 자동으로 적용되는 것

`edit` 명령은 `--profile phone` 으로 실행됩니다. 폰 CPU 에 맞춰

- **장면 전환 검출을 건너뜁니다** — 영상 전체를 디코딩해야 해서 폰에서 가장 비쌉니다.
  하이라이트는 소리와 대사만으로도 충분히 잡힙니다
- 결과물을 **720p 이하**로 맞춥니다 (원본이 더 작으면 그대로)
- 인코딩 속도 우선 설정 (`veryfast`, crf 26)
- 자막 모델은 가장 가벼운 것부터

화질을 더 원하면:

```bash
edit --profile quality
```

## 자주 겪는 문제

**`pkg install` 에서 오류가 나요**
플레이스토어 버전 Termux 입니다. 지우고 F-Droid 버전으로 다시 설치하세요.

**폰에 있는 영상이 목록에 안 보여요**
저장소 권한이 없는 경우입니다. Termux 에서 아래를 실행하고 **허용**을 누르세요.

```bash
termux-setup-storage
```

**편집 중에 멈춰요 / 앱이 죽어요**
안드로이드가 백그라운드 앱을 정리한 겁니다. 이렇게 해두면 덜합니다.

- 설정 → 배터리 → Termux 를 **제한 없음**으로
- 편집 중에는 화면을 켜 두거나, 최근 앱 목록에서 Termux 를 **잠금**
- `edit` 명령은 자동으로 wake-lock 을 겁니다 (알림에 뜹니다)

분석이 끝난 뒤에 죽었다면 다시 실행해도 분석은 다시 하지 않습니다.

**저장 공간이 부족해요**
편집 중에는 원본 + 중간 파일 + 결과물이 동시에 필요합니다.
원본의 **2~3배** 여유를 두세요. 다 쓴 작업은 아래로 정리합니다.

```bash
rm -rf ~/gameedit/work/mobile/jobs/*
```

**폰이 뜨거워져요**
정상입니다. 인코딩은 원래 CPU 를 다 씁니다. 케이스를 벗기고 충전기를 꽂아 두세요.
너무 뜨거우면 안드로이드가 속도를 낮춰서 더 오래 걸립니다.

**업데이트하려면**

```bash
cd ~/gameedit && git pull && pip install -e .
```
