# 폰만으로 쓰기 (안드로이드)

컴퓨터 없이 **갤럭시 안에서 편집기를 통째로 돌리는** 방법입니다.
Termux 라는 앱으로 폰 안에 리눅스 환경을 만들어 파이썬과 ffmpeg 를 설치합니다.

> 아이폰은 이 방법이 안 됩니다. iOS 는 앱 밖에서 프로그램을 돌릴 수 없습니다.

---

## 1. Termux 설치 (5분)

⚠️ **플레이스토어 말고 F-Droid 에서 받아야 합니다.** 플레이스토어 버전은
업데이트가 끊겨서 설치가 중간에 실패합니다.

1. 크롬으로 **https://f-droid.org/packages/com.termux/** 접속
2. **Download APK** → 설치 (출처를 알 수 없는 앱 허용 필요)
3. Termux 를 엽니다. 검은 화면에 `$` 만 보이면 정상입니다

## 2. 편집기 설치 (10~20분)

Termux 에 아래 한 줄을 붙여넣고 엔터 (길게 눌러서 붙여넣기)

```bash
pkg install -y git && git clone --depth 1 https://github.com/eukane/youtube-editing-.git ~/gameedit && bash ~/gameedit/termux설치.sh
```

중간에

- **저장소 권한 요청**이 뜨면 → **허용** (폰 안의 영상을 읽어야 합니다)
- 설치 중 뭔가 물어보면 → 그냥 엔터

끝나면 이렇게 나옵니다.

```
✅ 설치 끝!
이제 Termux 에서 아래 두 글자만 치면 됩니다.
    편집기
```

## 3. 쓰기

Termux 에서:

```bash
편집기
```

주소가 나옵니다.

```
📱 준비됐습니다. 크롬을 열고 아래 주소로 들어가세요
      http://localhost:8000/
```

**크롬을 열고 `localhost:8000` 을 입력**하면 편집 화면이 뜹니다.
(Termux 는 끄지 말고 그대로 두세요. 홈 버튼으로 나가는 건 괜찮습니다.)

화면에서

1. **폰에 있는 영상** 목록에서 편집할 영상 선택
   (갤러리·다운로드 폴더가 자동으로 보입니다)
2. 완성본 길이 선택
3. **✨ 편집 시작**
4. 끝나면 미리보기 → **⬇️ 폰에 저장하기**

크롬에서 그 주소를 **홈 화면에 추가**해 두면 앱처럼 쓸 수 있습니다.

## 대사 자막까지 넣으려면 (선택)

안드로이드에서는 PC 용 음성 인식(faster-whisper)이 돌아가지 않습니다.
대신 C++ 로 만든 **whisper.cpp** 를 설치합니다. 시간이 좀 걸립니다.

```bash
bash ~/gameedit/termux자막설치.sh
```

빌드에 5~15분, 모델 내려받기에 몇 분 걸립니다. 한 번만 하면 됩니다.
설치 후에는 편집할 때 자막이 자동으로 들어갑니다.

더 정확한 자막을 원하면 (대신 훨씬 느립니다):

```bash
bash ~/gameedit/termux자막설치.sh small
```

## 얼마나 걸리나요

폰 성능과 영상 길이에 따라 크게 다릅니다. **대략적인 감**만 적어 둡니다.
(실제 기기에서 측정한 값이 아니라 추정치입니다)

| 단계 | 1시간짜리 원본 기준 |
| --- | --- |
| 소리 분석 | 2~5분 |
| 자막(whisper.cpp base) | **30~60분** ← 가장 오래 걸립니다 |
| 컷 편집 + 밈·자막 합성 | 10분 결과물 기준 10~25분 |

**자막을 끄면 훨씬 빠릅니다.** 급할 때는 편집 옵션에서 "대사 자막" 스위치를 끄세요.

처음에는 **10분 이하 짧은 영상**으로 한 번 돌려보고 감을 잡는 걸 권합니다.

## 폰에서 돌릴 때 자동으로 적용되는 것

`편집기` 명령은 `--profile phone` 으로 실행됩니다. 폰 CPU 에 맞춰

- **장면 전환 검출을 건너뜁니다** — 영상 전체를 디코딩해야 해서 폰에서 가장 비쌉니다.
  하이라이트는 소리와 대사만으로도 충분히 잡힙니다
- 결과물을 **720p 이하**로 맞춥니다 (원본이 더 작으면 그대로)
- 인코딩 속도 우선 설정 (`veryfast`, crf 26)
- 자막 모델은 가장 가벼운 것부터

화질을 더 원하면:

```bash
편집기 --profile quality
```

## 자주 겪는 문제

**`pkg install` 에서 오류가 나요**
플레이스토어 버전 Termux 입니다. 지우고 F-Droid 버전으로 다시 설치하세요.

**폰에 있는 영상이 목록에 안 보여요**
저장소 권한이 없는 경우입니다. Termux 에서 아래를 실행하고 **허용**을 누르세요.

```bash
termux-setup-storage
```

**편집 중에 멈춰요 / 앱이 죽어요**
안드로이드가 백그라운드 앱을 정리한 겁니다. 이렇게 해두면 덜합니다.

- 설정 → 배터리 → Termux 를 **제한 없음**으로
- 편집 중에는 화면을 켜 두거나, 최근 앱 목록에서 Termux 를 **잠금**
- `편집기` 명령은 자동으로 wake-lock 을 겁니다 (알림에 뜹니다)

분석이 끝난 뒤에 죽었다면 다시 실행해도 분석은 다시 하지 않습니다.

**저장 공간이 부족해요**
편집 중에는 원본 + 중간 파일 + 결과물이 동시에 필요합니다.
원본의 **2~3배** 여유를 두세요. 다 쓴 작업은 아래로 정리합니다.

```bash
rm -rf ~/gameedit/work/mobile/jobs/*
```

**폰이 뜨거워져요**
정상입니다. 인코딩은 원래 CPU 를 다 씁니다. 케이스를 벗기고 충전기를 꽂아 두세요.
너무 뜨거우면 안드로이드가 속도를 낮춰서 더 오래 걸립니다.

**업데이트하려면**

```bash
cd ~/gameedit && git pull && pip install -e .
```
